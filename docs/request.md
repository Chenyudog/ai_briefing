# 11.18第一版任务文档
## 1.要求
### 1.1 创建一个网站 内容是关于前沿ai的新闻和前沿机器人的新闻
新闻包括openai  a场 等等中美的ai企业的新闻

然后机器人的新闻 包括vla的论文 然后一些关于机器人大厂的一些论文
### 1.2 你的任务不仅仅是完成一个网站  更重要的是教会我如何利用ai搭建一个网站
你可以通过写文档的方式想我解释 但是不要向我提到一句代码 可以跟我说思路
我目前是小白 对前后段和服务器完全不懂

### 1.3 网站第一版叫什么 打开以后能看到什么
网站先叫 AI 大事 首页分成前沿 AI 和机器人 / VLA 两个频道
首页能切换频道 每条新闻显示标题 一句话摘要 来源和原文发布日期 按原文发布日期从新到旧排列
点开新闻以后 能看到发生了什么 为什么值得关注 还能点链接去看原文

### 1.4 新闻从哪里来 每条新闻要写清楚什么
优先用公司官方公告 研究团队主页 论文原文和作者发布的演示 有原始来源就把原文链接放上去
新闻里要分清新品发布 研究成果和厂商预告 论文能确认发表状态的话 就写清是预印本还是已正式发表
机器人和 VLA 的内容要尽量写清结果来自仿真 实机演示还是实机评测 原文没说清楚就标明未明确

### 1.5 第一版怎么发新闻
先做一个只有管理员能用的编辑后台 可以新增和修改新闻 也可以先存草稿再发布
我先自己选几条消息 让 AI 帮我整理标题和摘要 核对原文以后在后台发布
第一版先在本机跑通 定时采集 自动去重 DeepSeek 自动生成草稿和公开上线放到后面做

### 1.6 怎么教我用 AI 搭建这个网站
每完成一步 写一小段说明 告诉我这一步怎么向 AI 提要求 AI 做出了什么 我应该去哪里看效果
按我在网站里的操作讲 比如我点发布以后 页面怎么把请求交给后端 后端怎么改数据库 首页刷新后为什么能看到
也告诉我每一步怎么自己验收 如果效果不对 我该怎么把问题描述给 AI 用文字讲就行

### 1.7 第一版怎么验收
两个频道各发布至少一条带原文链接的新闻 首页切换频道时能看到对应的内容
新建一条草稿 确认首页看不到 发布以后确认它出现在正确的频道 刷新后还在 详情页能打开原文
退出管理员账号以后 访客仍然能看已发布的新闻 不能进入后台发稿

### 1.8 每完成一版怎么提交到仓库
每完成一版并按这一版的要求验收通过 就把这一版的改动提交到 Git 并推送到已经关联的 GitHub 远程仓库
推送完成后 告诉我这一版提交到了哪个分支 提交说明是什么

### 1.9 Git commit 怎么写
提交说明遵守 Conventional Commits 规范 格式是 英文类型: 中文说明 冒号用英文半角 冒号后加一个空格
根据实际改动选择英文类型 比如 feat 是新增功能 fix 是修复问题 docs 是更新文档 chore 是仓库维护 也可以用 refactor test perf ci build 等合适的类型
需要指出改动范围时 可以写成 英文类型(范围): 中文说明 中文说明要写清楚具体改了什么
比如 `feat: 新增机器人 VLA 新闻频道` `fix(feed): 修复首页新闻排序` `docs: 补充第一版验收要求` `chore: 初始化仓库`
