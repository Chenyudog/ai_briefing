# 跟 AI 从零搭出「AI 大事」

每次交给 AI 一个能在浏览器里验证的结果。把需求文档留在项目里，让下一次对话能接着已有的工作。下面每一步都可以单独复制引号里的话，请 AI 继续执行，然后照着验收。

## 1. 先搭访客能打开的首页

**怎么提要求**

> 我要在本机打开一个叫「AI 大事」的网站。首页有「前沿 AI」和「机器人 / VLA」两个频道。每条新闻给我标题、一句话摘要、来源和原文日期。请把最新的原文放在最上面，完成后告诉我地址和验收方法。

**AI 做了什么**

浏览器里你能看到和点击的部分叫前端。你点「机器人 / VLA」时，浏览器向本机正在运行的网站服务请求这个频道。负责处理请求的部分叫后端。它从数据库取出这个频道的已发布新闻，按原文日期排好，再把页面交给浏览器展示。数据库是电脑里长期保存新闻和发布状态的地方。本机服务开着时，浏览器才能向它索取页面。可以请 Codex 按项目说明启动服务。

**去哪验收**

打开首页，来回切换两个频道。在「前沿 AI」频道核对较新的 DeepSeek 发布排在 OpenAI 前面。切到「机器人 / VLA」后，应当看到 Physical Intelligence、Google DeepMind 的文章。

**出问题怎么说**

> 我在首页点「机器人 / VLA」，选中的频道变了，但列表还显示 DeepSeek。请复现这个点击过程，检查后端取出的是哪个频道，并用浏览器确认修复结果。

## 2. 做出能追溯到原文的详情

**怎么提要求**

> 点新闻标题要看到「发生了什么」「为什么值得关注」和「查看原文」。把新品发布、研究成果、厂商预告或预览标清。机器人论文要写发表状态，也要说明是仿真、实机演示还是实机评测。原文说不清就写「未明确」。

**AI 做了什么**

每条新闻有自己的详情地址。点击标题时，后端找到对应条目并显示摘要、两段详情和原文信息。点「查看原文」会在新标签页打开作者或机构的页面。日期取自链接对应的原文，例如链接是论文预印本，就用预印本的发布日期。

**去哪验收**

在机器人频道打开 π₀.₇，检查详情中的「预印本」「实机评测」，再点「查看原文」。对照作者、原文日期和实验描述。回到 AI 频道，确认「V4 预览版」有预览类型标记。

**出问题怎么说**

> π₀.₇ 的详情页写了实机评测，但我在原文里只找到一段视频。请告诉我哪一节支持这个说法。证据不足时，请把标签改为实机演示或未明确。

## 3. 做只有管理员能用的后台

**怎么提要求**

> 右上角给我一个编辑后台入口。首次在本机打开时让我自己设置密码。登录后能新建、修改和发布，退出以后还能读新闻，但访问编辑页面要重新登录。

**AI 做了什么**

你第一次设置密码后，后端保存用来核对密码的摘要。每次登录成功，浏览器会获得一个登录凭据，后续打开后台或提交表单时会带上它。后端先核对凭据，再决定是否允许编辑。点击退出后，当前浏览器的登录凭据会被清除。

**去哪验收**

点击「编辑后台」，设置至少 12 个字符的密码。进入后台后点「退出登录」，在同一个浏览器中再打开后台。已发布文章应继续可读，编辑后台应显示登录页。输入正确密码重新进入，尝试打开一条旧新闻的编辑表单。

**出问题怎么说**

> 我点退出后直接打开了刚才的编辑地址，仍然能看到编辑表单。请检查退出状态和后台入口的权限，并验证退出后直接打开编辑地址会进入登录页。

## 4. 从存草稿走到发布

**怎么提要求**

> 后台表单允许我只写标题先存草稿，也让我补齐来源、日期、原文链接和详情后发布。草稿不能出现在任何访客页面，发布后应该出现在选中的频道，刷新仍然可见。

**AI 做了什么**

你点「存为草稿」，浏览器把表单和保存动作交给后端。后端检查登录状态，再将新闻及草稿状态存入数据库。首页和访客详情只读取已发布的记录。你点「发布」，浏览器再次提交表单。后端核对必填信息，在数据库中把同一条新闻写成已发布。刷新首页时，浏览器重新请求页面，后端从数据库读到更新后的状态，新闻便进入该频道。关闭浏览器或重启网站后，数据库仍会保留这些记录。

**去哪验收**

1. 选一条愿意保留的原始新闻，在后台点「新建新闻」，选择频道，填一个容易辨认的标题，点「存为草稿」。
2. 用隐私窗口打开首页，切到对应频道，确认没有这条稿件。
3. 回到后台补齐字段并发布。刷新访客窗口，确认出现在正确的频道，按原文日期找到它。
4. 打开详情并点击原文。回后台改一次摘要，更新后再用访客窗口确认变化。
5. 退出管理员，确认仍能读新闻，返回后台时需要重新登录。

**出问题怎么说**

> 标题是「……」，频道选的是「……」。我点发布后页面提示已发布，但切到这个频道并刷新，还是找不到。请检查数据库保存的状态、频道和原文日期，再按我的操作复现。

## 5. 用 AI 帮你整理一条稿件

**怎么提要求**

> 我给你一条原文链接。请只根据原文帮我拟标题、一句话摘要、来源、原文日期、新闻类型、「发生了什么」和「为什么值得关注」。如果是机器人论文，再给我发表状态和实验证据，标出原文在哪一段支持。缺少的信息请写「未明确」。

**你来验收**

打开原文，对照日期和机构名称，核对 AI 说的是作者实测、演示还是后续计划。如果原文来自论文预印本平台，且你只确认到这个版本，就标「预印本」。核对后复制到后台，存草稿并预备发布。

## 6. 让 AI 提交这次成果

**怎么提要求**

> 请逐项验收第一版。通过后提交到 Git 并推送到项目已经关联的 GitHub 仓库。提交说明用英文类型和中文说明。推送后告诉我分支、提交编号和说明。

**去哪验收**

Git 提交是在本机保存一版项目文件。推送是把这版文件同步到 GitHub。打开仓库的提交历史，找 AI 报告的那条记录，核对分支和说明。你的管理员密码与发布后新增的本机稿件保存在这台电脑的数据库中。

## 第二版 · 自己启动和检查新版界面

**怎么提要求**

> 把网站留在本机。请给 Ubuntu 装一个菜单入口，我点开就能访问首页。首页改成科技新闻刊物风格，最新一条作为头条，下方继续按原文日期排列。

**AI 做了什么**

你点击应用图标后，Ubuntu 在后台启动网站服务，再用浏览器打开首页。服务只接收这台电脑发来的请求。首页从所选频道取出最新的稿件作为头条，其他稿件按日期列在下面。编辑、保存和发布的操作仍在同一个后台完成。

**去哪验收**

在 Ubuntu 应用菜单点「AI 大事服务器」。打开后切换两个频道，确认各频道的头条与列表都按原文日期排列。把浏览器窗口缩窄，检查标题、来源和日期能完整显示。右击应用图标选「停止服务」，刷新首页应暂时打不开。再次启动后，新闻应重新出现。

**出问题怎么说**

> 我在 Ubuntu 点击「AI 大事服务器」，但浏览器显示无法连接。请检查服务有没有启动，并按同一个菜单入口复现。

## 个人手记版 · 写第一篇文章

从 Ubuntu 应用菜单打开「我的手记服务器」。点「考研历程」，再点「写第一篇文章」。用原来的管理员密码登录，填上标题和正文。写作日期默认为今天，也可以改成事情发生的那一天。

点「存为草稿」后，文章会保存在后台。等你想让它出现在首页时，再点「发布」。回到「考研历程」，点击标题，就能按你写下的段落阅读全文。后续文章会按写作日期从新到旧排列。
