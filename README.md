# 我的手记

在本机阅读思考、备考与日常随笔，并通过管理员后台手动选稿、存草稿和发布。

## 自己启动服务器

1. 在 Ubuntu 应用菜单搜索 **我的手记服务器**，点击打开。浏览器会打开 [我的手记](http://localhost:8765/)。
2. 点击右上角「编辑后台」。首次使用时，按页面提示设置至少 12 个字符的密码。
3. 关掉浏览器后，可以重新点应用图标打开页面。要停止服务，在应用图标上右击，选择「停止服务」。下次启动时，已有稿件和密码会从本机数据库读回。

这台电脑上的菜单入口已经安装。将项目克隆到另一台 Ubuntu 电脑时，在文件管理器打开项目的 **deploy** 文件夹，右击 **install-launcher.sh**，在属性里允许它执行，然后选择「作为程序运行」。首次启动需要 Python 3.10 或更新版本、pip 及网络连接。
