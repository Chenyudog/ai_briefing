# AI 大事

在本机阅读前沿 AI 与机器人研究简报，并通过管理员后台手动选稿、存草稿和发布。

## 打开网站

在 Codex 中打开这个项目，发一句「请通过项目里的启动文件启动 AI 大事，并告诉我浏览器地址」。启动文件名是 **start.sh**，首次启动需要本机已有 Python 3.10 或更新版本以及 pip，并联网安装依赖。启动成功后，在同一台电脑打开 [AI 大事](http://127.0.0.1:8765/)。

首页提供「前沿 AI」和「机器人 / VLA」两个频道。点击右上角「编辑后台」，首次打开时自己设置管理员密码。后续用这个密码登录。完成阅读和编辑后，可请 Codex 停止本地服务。下次启动时，已有稿件和密码会从本机数据库读回。
